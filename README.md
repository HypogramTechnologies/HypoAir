# HypoAir - Ventilador Inteligente com Automação

Sistema inteligente de controle de ventilação utilizando **IoT** para monitoramento de temperatura e presença, garantindo conforto térmico e eficiência energética.

## 📋 Sobre o Projeto
O projeto consiste em um ventilador USB automatizado que reage às condições do ambiente. O sistema resolve problemas como o uso ineficiente de energia e a necessidade de intervenção manual constante.

### Principais Funcionalidades
* **Acionamento Automático:** Baseado em sensores de temperatura e presença.
* **Controle Manual:** Interface via dispositivo móvel para ajustes remotos.
* **Monitoramento em Tempo Real:** Visualização de dados de temperatura e umidade.

## 🏗️ Arquitetura do Sistema
O sistema é dividido em três camadas principais:
1.  **Percepção:** Sensores e atuadores.
2.  **Rede:** Comunicação via WiFi, Bluetooth ou LoRa (utilizando protocolo **MQTT**).
3.  **Aplicação:** Interface de usuário para monitoramento.

## 🛠️ Materiais e Tecnologias

### Hardware
* **Microcontrolador:** ESP32.
* **Sensores:** Sensor de temperatura e umidade, e sensor de presença.
* **Atuadores:** Módulo relé ou transistor e um Ventilador USB.
* **Componentes Adicionais:** Protoboard, jumpers, resistores e fonte USB.

### Software
* **Linguagem/IDE:** Arduino IDE.
* **Protocolo de Comunicação:** MQTT.
* **Bibliotecas:** Bibliotecas específicas para os sensores utilizados.
